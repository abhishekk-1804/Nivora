# Screenshot assets

This directory is reserved for screenshots captured from the running Nivora application. The screenshot pack referenced in the repository brief was not present in the current checkout, so no images have been invented or copied into this directory.

When the pack is available, use these relative paths:

```text
assets/screenshots/
├── 01_onboarding.png
├── 02_first_run.png
├── 03_tracking.png
├── 04_insights.png
├── 05_security_settings.png
└── Nivora_Screenshot_Overview.png
```

Screenshots should be captured from the same app build, use consistent dimensions, and avoid real health information. Captions in the README should describe only what is visible. A screenshot demonstrates a UI surface. It does not prove database persistence, encryption, authentication behavior, or network isolation.
